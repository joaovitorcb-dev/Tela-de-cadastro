# 🔐 Tela de Login com PySimpleGUI

## 📌 Descrição

Aplicação de login desenvolvida em Python utilizando PySimpleGUI. Permite ao usuário inserir nome e senha, validar credenciais e receber mensagens de sucesso ou erro.

---

## 🚀 Tecnologias

* Python
* PySimpleGUI

---

## ⚙️ Funcionalidades

* Campo de usuário
* Campo de senha (oculto)
* Botão "Entrar"
* Checkbox "Salvar senha"
* Validação de login

---

## ▶️ Como executar

1. Instale o PySimpleGUI:

```bash
pip install PySimpleGUI
```

2. Execute o arquivo:

```bash
python nome_do_arquivo.py
```
